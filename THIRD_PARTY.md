# Third-party material

The source datasets originate from RCAEval and the TORAI data release. Their source records distribute the data under CC BY 4.0. Dataset provenance and transformations are described in `datasets/README.md` and the event mapping.

CARE belongs to its original authors. The adapter uses commit `7f17d5b4e077489acf7ad6f91b3bdd02a16a8f7d` of their repository. The publication copy retains a downloader and hashes rather than redistributing author source without a verified license grant. A downloaded local copy is excluded by `.gitignore`.

The original TopoTrace-AD code has not been assigned a new license by this packaging step. The authors should select its license before making the repository public. Do not apply a project license to third-party data or author code.
